# Start here

This folder is the GRIND project root. The original starter and agent-setup packages have been consolidated here; no copying or extraction is needed.

1. Read [AGENTS.md](AGENTS.md) for coordinator rules and specialist responsibilities.
2. Read [README.md](README.md) for project scope and file layout.
3. Follow [docs/README.md](docs/README.md) for the complete design and requirements reading order.
4. Check [docs/AGENT_STATUS.md](docs/AGENT_STATUS.md) and [live tasks](docs/planning/TASKS.md) for actual progress, file ownership and next work.
5. Before code or maintenance work, read [React Native standards](docs/engineering/REACT_NATIVE_STANDARDS.md) and [maintenance workflow](docs/MAINTENANCE.md). Check [test coverage](docs/engineering/TEST_COVERAGE.md) for existing compliance gaps.

M0/M1 local foundation work is now authorized and in progress. Read [docs/SETUP.md](docs/SETUP.md) for app/local-backend commands and current [status](docs/AGENT_STATUS.md) before running checks. Hosted changes, deployments, provider spend and later milestone work are separately gated.

`agents/` defines specialist roles. These Markdown files do not themselves enable delegation; verify native availability when needed. Native architect and reviewer delegation was exercised successfully during the initial review.
